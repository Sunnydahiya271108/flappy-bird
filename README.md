# Mini Flappy Bird

A simple Flappy Bird-style game built with Python and Tkinter.

## Description

This project is a lightweight arcade game inspired by the classic Flappy Bird. The player controls a bird and must avoid incoming pipes while trying to score as many points as possible. The game includes a start screen, score tracking, pause support, theme switching, and persistent high-score saving.

## Features

- Simple and responsive gameplay
- Randomized pipe generation
- Score and high-score tracking
- Pause and restart support
- Theme switching between default, evening, and night modes
- High score saved to a local file
- Built with Python's Tkinter GUI library

## Requirements

- Python 3.x
- Tkinter (usually included with Python on most systems)

## Run the Game

Open a terminal in the project folder and run:

```bash
python game.py
```

If you are using a system where `python` points to Python 2, try:

```bash
python3 game.py
```

## Project Files

- `game.py` - Main game logic and UI
- `bird.png` - Bird sprite image
- `high_score.txt` - Stores the saved high score
- `README.md` - Project documentation
